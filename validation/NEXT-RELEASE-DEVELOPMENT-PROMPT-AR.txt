- أرفق IPA وAPK وSHA256SUMS وتقرير عربي واضح: الموجود، المؤجل، الأرقام الحقيقية، قيود التعلم والأجهزة، وطريقة الاستعمال والتراجع. لا ترفع تعريب RDR2 الخاص أو مفاتيح أو رموز اقتران أو تسجيلات اللعب.
- إذا احتجت تقسيم الدفعة إلى إصدارات، بيّن نطاق كل إصدار والناقص، ولا تعتبر المهمة كاملة أو كل المتطلبات ناجحة قبل تحقيق النطاق المطلوب أو إبلاغ المستخدم بمانع حقيقي محدد.
- استمر حتى روابط تنزيل الأصول الفعلية. لا تكتف بخطة أو تعديلات غير مبنية.

ابدأ الآن: افحص الحالة والملفات، سجّل خطة تنفيذ داخلية ومصفوفة قبول لهذه المتطلبات، وابدأ أول تغييرات واختبارات مستقلة قابلة للمراجعة. أولوية مقترحة: إصلاح الاتصال/wake والمعاينة المستمرة، ثم ملفات الألعاب ووجهات العرض وROI والقوائم/Setup وQR، ثم مقارنة النماذج والتحسين الآلي. يجوز ترتيب التبعيات عمليًا دون إسقاط أي متطلب.
