# معاينة الجودة 1 — نطاق القبول المعتمد

هذه معاينة للفحص الميداني، وليست إعلان اكتمال الوحدات A–I. عدّل تفويض المستخدم الأحدث شرط التسليم السابق لهذه المعاينة تحديدًا.

- ربط النص المتدرج في FramePipeline وAppModel مستبعد من التجميع الإنتاجي خلف `GAMELINGO_TYPEWRITER_RESEARCH` غير المعرّف في إعدادات البناء. لا خيار له في واجهة المعاينة. تبقى أبحاث Core والاختبارات محفوظة، ولا يُحسب نجاح البحث المحمول قبولًا لميزة إنتاجية.
- جميع ميزات الجودة الأخرى OFF افتراضيًا. لا إضافة Apple Translation أو تقسيم جمل أو حماية أسماء بالرموز.
- ملف `iOS/Scripts/preview-tests.json` يحدد 42 حالة أصلية منفردة تشمل Argos الحقيقي وSQLite والاستيراد والأسماء والتصحيحات وWSS/OkHttp والاتصال وهوية TLS. أي نتيجة مفقودة أو فشل أو إعادة محاولة أو تجاوز غير معتمد يرفض البوابة. الحالتان المسموح بتجاوزهما هما قراءة بيانات حماية الملفات غير المتاحة في المحاكي؛ الحماية الفعلية تحتاج iPhone.
- حالات Vision/FramePipeline المعتمدة على الصور ومنتقي Files بواجهة المستخدم مؤجلة لقبول يدوي على iPhone، وليست ناجحة أو محذوفة. الاستيراد والتحقق من المحتوى وتسجيل الامتدادات وتكوين المنتقي البرمجي تظل ضمن الفحوص الأصلية؛ هذا لا يثبت نجاح التفاعل مع Files على الهاتف.
- تبقى فحوص التجميع وCore والتكافؤ مع الريليز وRDR2 الحقيقي الخاص والتغليف. البناء المحدد `quality-preview-1` على `macos-15-intel` وXcode 16.4، وأرشيف iPhone ARM64 غير موقّع.
- لا تغيير Windows أو PS5 أو Chiaki أو VideoToolbox أو معدل الصور/ROI أو دقة البث أو TLS/الاقتران أو الخلفية والاستعادة أو منع التكرار وساعات TV.
- APK 0.6.2-quality.1 المعتمد يُعاد استخدامه دون بناء، ما دام كود Android لم يتغير. النشر في prerelease جديد فقط بعد نجاح فحوص المعاينة وفحص IPA وهوية وتوقيع APK، دون بيانات اللعبة الخاصة أو المفاتيح أو النموذج التجريبي.

لا تُستبدل أدلة المحاكي بأدلة أجهزة فعلية. تقرير التسليم النهائي يذكر التشغيل والمصدر والبصمات والحدود الحقيقية.
