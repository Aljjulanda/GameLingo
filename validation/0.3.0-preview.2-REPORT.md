# GameLingo 0.3.0 Preview 2 — document import

## Reported symptom

The user downloaded `rdr2-Arabic.glpack` on iPhone but the file was disabled in the picker. There was no package validation error. The exact installed build and the provider's assigned UTI were not available, so their contribution is unconfirmed.

## Change

- Build 7 exports GameLingo's owned `.glpack` type, explicitly conforming to `public.data` and `public.archive`, and registers it as a viewable document.
- The game pack picker accepts `public.item`, so provider-assigned generic/dynamic types cannot exclude a downloaded pack. Selection is not acceptance: both import entry points require a local `.glpack` URL, then use the existing coordinated, security-scoped ZIP/checksum/manifest/SQLite validator.
- Files/Open In routes to the same importer and displays the translation library. HTTPS URLs are not fetched. Import is refused while a translation session or another import is active.
- No package conversion, model changes, TV APK or PS5/networking changes are required. Existing downloaded packs remain valid.

Apple requires regular custom document types to conform to `public.data` and describes exporting an owned type and registering document handlers: [type declarations](https://developer.apple.com/documentation/UniformTypeIdentifiers/defining-file-and-data-types-for-your-app), [custom document sample](https://developer.apple.com/documentation/uikit/building-a-document-browser-app-for-custom-file-formats).

## Validation scope

Local Windows source validation, four packaging tests and seventeen converter tests passed. Apple CI adds tests for the built app's UTI/extension registration, generic provider type eligibility, uppercase extension, valid import, duplicate import guard, active-session protection, rejection of remote URLs/wrong extensions and corrupted `.glpack` content. The normal Swift, native data and Apple integration suite must pass before release publication.

Simulator/API tests cannot establish how a specific iPhone Files provider displays the picker. Also verify Files → Share/Open In → GameLingo. No need to rename or download the pack again.
