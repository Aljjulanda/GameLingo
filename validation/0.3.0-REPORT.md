# GameLingo 0.3.0 Translation Packs preview

## Implementation and preserved baseline

This is an incremental feature on branch `codex/0.3.0-translation-packs`, based on the successful 0.2.1 preview. Accepted stable `ios-v0.2.0`, main `22139da223b92b17cb8e6b5b7b64e3f70c2530cc`, recovery tag `stable/real-device-0.2.0` and prior release assets remain protected. The production TCL is already 0.6.1 (9), updated at the user's request with pairing/preferences preserved. No production TV source or Windows source was changed for Translation Packs. See [baseline evidence](0.3.0-BASELINE.md).

Delivered components are a reusable data-only converter, versioned `.glpack`/SQLite format, native iPhone Files import and managed library, explicit game selection, indexed lookup before Argos, conservative wrapped-speaker extraction, Smart Reading integration and bounded diagnostics. The application stays usable with no packs. Chiaki streaming, VideoToolbox, no-continuous-rendering behavior, background audio, reconnect policy, context settings, styling, TLS and protocol v1 are preserved.

The updated application is **iOS 0.3.0 (6)**, bundle `dev.gamelingo.ios`, unsigned for the existing external signing process. There is no need for an additional TV update beyond installed 0.6.1.

## Installer and actual localization data

The supplied `Arabic-RDR2.exe` was **never executed**. No DLL, ASI, embedded program or installer script was invoked, no registry entry was changed and no PC mod was installed. Static PE/CLR analysis used pinned `dnfile` 0.18.0 / `pefile` 2024.8.26, reading only data resources. The pinned public download was also verified byte-for-byte against the supplied file before transient CI analysis.

| Input/resource | Size | SHA-256 |
|---|---:|---|
| Supplied installer | 11,941,456 bytes | `3eaead8f4e851ad6c6c9a894415799e047928c522f009a632830cc3826fd0598` |
| Extracted text table | 25,178,638 bytes | `682d1d063f8e77c384beacc3b5fe8b8e3165e7eb5d270ab6f4231aca1d63e377` |

The resource `r_text.gxt2.gz` is gzip inside a .NET manifest-resource container. Its expanded `.gxt2` is a **UTF-8/BOM text export**, not a binary GXT2 table or RPF archive. Other installer resources include fonts and LML/ASI components, which are unnecessary to GameLingo and were not installed. Embedded installer configuration identifies 1.5; LML metadata separately says 1.0.0, so those version labels are not conflated.

The converter also has a bounds-checked binary GXT2 reader for the layout researched in [CodeWalker's actual reader](https://github.com/dexyfex/CodeWalker/blob/master/CodeWalker.Core/GameFiles/FileTypes/Gxt2File.cs). This does not claim support for arbitrary game installers. Text parsing, identifier normalization, presentation conversion, extraction and shared join/package generation are separate extension points.

The English source is [cedricalpatch's RDR2 text dump](https://github.com/cedricalpatch/Red-Dead-Redemption-2-Text-Files/tree/cdb2b8ab3134291a19a86d8d35fe0bd48cb8f926), pinned at `cdb2b8ab3134291a19a86d8d35fe0bd48cb8f926`. Its source description references PC/Frontier Update content; it is not a claim of parity with the user's current PS5 game revision. Inspection found 142 files needing the explicit strict UTF-8/CP1252 policy. The default remains strict UTF-8, with no silent replacement of malformed bytes. Credit-file/non-record lines are reported separately.

The additional [Nexus Official Language XML Pack](https://www.nexusmods.com/reddeadredemption2/mods/10249?tab=description) was investigated as a possible alternate English adapter/source. Its landing page was intermittently accessible; file contents were not acquired or compared. It contributes **zero** claimed additional IDs or coverage. No assumption of equivalence or completeness was made.

Textual RAGE labels are joined through lower-case ASCII Jenkins one-at-a-time hashes; hexadecimal IDs are canonicalized without discarding the original ID. English-ID conflicts are detected and excluded rather than arbitrarily selected. Original Arabic target variants remain separately addressable rows.

## Arabic order and game markup

The Arabic table contains presentation forms in a producer-specific visual order. Plain NFKC alone would unshape letters but leave words backwards. Whole-string reversal would break Latin islands, numbers, controls and lam-alef. The explicit adapter instead respects hard/timing boundaries, protects Latin/numeric islands, mirrors bracket glyphs and expands presentation ligatures after ordering. Observed vowel marks precede their visual base in this producer, so the conversion handles their order separately from punctuation. Latin accents and mixed punctuation have regression cases. Already logical strings are not reversed.

Only known `~z~`, `~n~`, and `~sl:...~` controls are interpreted as subtitle, hard break and timing/segment metadata. Unknown formatting/input tokens and runtime placeholders are retained but ineligible, rather than silently deleting buttons/variables or inventing PS5 values. Flag counts overlap: 18,645 rows have unresolved markup/placeholders, 67 complex visual-order cases, 141 no-Arabic cases and 36 empty cases. The union of blocked rows is 18,715. Original/source hashes and per-file parse diagnostics are in the private conversion report.

This is not a universal inverse-bidi or full linguistic correction system. Six converted examples, including vowel marks, were rendered and visually reviewed on the real TCL. Further game-specific linguistic review remains necessary; human authorship/translation method was not independently established merely from the installer branding.

## Package import and indexed hybrid lookup

See [the complete format/security specification](../tools/pack_converter/FORMAT.md) and [converter CLI instructions](../tools/pack_converter/README.md). The closed format has exactly a manifest, database and checksums; no executable functionality. Import bounds members, total compressed input, expansion ratio, row count, text lengths and versions; rejects duplicate/unsafe paths, symlinks, schema additions, views, triggers and virtual tables, including misleading SQLite-like names; verifies CRC/SHA, UTF-8, normalized keys and SQLite integrity before activation.

Files URLs are security-scoped/coordinated and copied to managed staging storage. A new UUID directory and atomic registry commit replace a same-game pack only after validation; failed imports preserve the working registry/pack. Selection/enabled state persist independently of PS5/TV credentials. File protection permits access after first authentication, while actual locked-screen execution remains governed by the existing iOS/background policy. The selected database remains open through reconnects and unrelated library changes. Startup checks its hash again; damage/unavailability yields a warning and Argos fallback.

Only the selected, enabled and validated game's database is queried. Exact source is preferred, followed by conservative normalization. Numbers/signs, negations, names, actions, directions and destinations are retained; no global similarity scan or first-result choice is used. Questions are preserved. Conflicting targets, blocked rows or more than 32 matching records fall back. The cache has 32 entries; SQLite uses a 2 MiB page cache, no mmap, fixed prepared statements, read-only immutable access, trusted-schema disabled and bounded execution deadlines. The full localization is not loaded as a gameplay dictionary.

Approximate matching is intentionally **disabled** in this first version. A missing character can reduce hit rate and safely use Argos. There is no neural-context claim: existing 1–20 sentence/default-5 context and explicit user terminology rules retain their behavior and priority. A package does not provide automatic contextual disambiguation.

The source is resolved before the existing event is published. The same event/expiry/stability path handles pack and Argos results; no second card or delayed pack replacement is introduced. Cached results and unchanged event identity prevent reconnect replay. Statistics count admitted dialogue IDs, actual pack lookup decisions, exact/normalized matches, rejected ambiguity, lookup fallbacks, Argos requests (including its cache path), average lookup time and the last-120-sample p95. No-pack/disabled state causes no database lookup. Counters are not a permanent dialogue history.

## Speaker and Smart Reading behavior

Leading `(Arthur)`, `[Arthur]`, colon labels and supported separate/spatial labels are removed from the engine/lookup source only when name evidence passes the classifier. Metadata contains the clean name; existing TV 0.6.1 supplies the single colored inline name and external RTL colon. Multiword/apostrophe/period names and legitimate digit-bearing labels are supported; low-case OCR can use a known-name hint. HUD and sound-effect examples remain ordinary text, with no invented speaker. Meaningful narration/action brackets are preserved. Optional pack name hints augment the existing manual dictionary only for the active validated game; the RDR2 pack does not invent a name list from uncertain IDs.

Smart Reading remains manual and retains its current paragraph/chunk/page bounds. Complete chunk lookup searches document, menu and general categories in the selected pack, then the original Argos mechanism. It does not use partial-string replacement or automatically overlay menus. Long entries or timed subtitle sequences may not match a currently visible shorter chunk; fallback is deliberate. Text embedded in textures/images is only accessible to the extent that the existing OCR flow recognizes it.

## Verified native lifetime fix

A CI integration run exposed `thread::join failed: Resource deadlock avoided` after native inference. The old Objective-C++ generation callback strongly captured `self`. CTranslate2 can resolve the synchronous future before its worker releases the job/callback; a last release there can destroy/join the owning pool from that same worker. The narrow fix captures a standalone shared atomic cancellation flag instead of the engine object. Model, tokenizer, thread count, decoding options and engine version are unchanged. This is a lifecycle fix to the existing adapter, not a replacement translation engine or PS5 streaming rewrite.

The diagnosis was checked against the pinned CTranslate2 worker/future ownership pattern (see [worker lifecycle](https://github.com/OpenNMT/CTranslate2/blob/617405f4b050e994e829d527da6caa0e0030afe7/src/thread_pool.cc) and [synchronous future collection](https://github.com/OpenNMT/CTranslate2/blob/617405f4b050e994e829d527da6caa0e0030afe7/src/translator.cc)). A ten-construction/immediate-retirement regression passed in the successful intermediate run; final results are recorded below. No historical physical-device crash is claimed from this CI finding.

## Delivery, licensing and remaining acceptance

Public release: `ios-v0.3.0-preview.1`, prerelease only; stable 0.2.0 stays latest stable. Public assets are the unsigned IPA, source/converter, reports, validation JSON and checksum manifest. **No third-party translation database, installer or private sample image is publicly redistributed.** The generated partial `RDR2-Arabic.glpack` and full input/coverage reports are delivered locally in `Desktop/GameLingo-Packs-0.3.0`.

The [Arabic PC source page](https://arabic-pc.github.io/rdr2.html) credits KG Studio and Arabic PC revisions; permission between those parties does not establish GameLingo redistribution rights. Loader MIT licensing does not license localization text. No permissive content license was identified for the English dump. Permission remains unestablished, so use the documented local-generation/import workflow. There are no model-generated entries passed off as supplied localization.

On iPhone, sign/install the IPA with the same external identity/bundle identifier to retain data according to the signer. Transfer the local `.glpack` to Files/iCloud Drive, open GameLingo → Translation → Game Translation Library → Add Pack, wait for validation, inspect it and manually select RDR2. Keep the existing Argos model installed. No computer is needed after import, and adding later compatible packs does not require rebuilding the app.

Physical acceptance still required: current RDR2 PS5 English subtitles and wrapped names; ambiguity/no-hit/number/negation examples; manual Smart Reading and return; app restart; controlled PS5/TV/network interruption with no stale replay; other-app/locked-screen continuity; and equivalent-workload phone resource/hit-rate counters. The user's uninterrupted half-hour trial belongs to stable 0.2.0 and is not new 0.3.0 evidence. Neither partial ID coverage nor CI success establishes full-game acceptance.
