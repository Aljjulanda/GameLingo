## Changes

- The control no longer declares `openAppWhenRun = true`. On iOS 18 it uses
  `ForegroundContinuableIntent` to execute in the containing app process without
  requesting a foreground transition. The app and intent use one `AppModel.shared`.
  Removed the process-local notification / defaults command polling path.
- A start during the model's existing cold-launch load is retained. Missing
  console/model/ROI setup throws a localized error instead of silently accepting
  a request. Explicitly starting a restored or suspended session initializes the
  native connection lifecycle again; no PS5 wake operation was added.
- The toggle represents enabled session intent, including starting/recovering,
  so another press can cancel an unfinished connection. Connected state remains
  separately represented by `isActive`; the short freshness lease is retained.
  A missing signed App Group is reported by the control value provider.
- Background start uses the existing finite UIKit execution opportunity, now
  accounted for explicitly in session policy. The deadline is 20 seconds or the
  earlier OS expiration. This is **not** permission for indefinite OCR in the
  background. Existing optional background-audio experiment is unchanged and
  is not enabled automatically. Force-quit/cold-launch delivery and sustained
  operation must be verified on a real signed iPhone.
- Dialogue OCR now rejects isolated registration-style codes, numeric-only
  observations, common HUD counters, and a narrow set of uppercase signs before
  speaker grouping and translation. Removing a plate cannot leave a detached
  known speaker to translate alone. Ordinary sentences containing money, times,
  room numbers, codes, or quoted plates remain eligible. This is conservative
  text-based filtering, not a general visual scene classifier; some signs and
  unusual plates can remain ambiguous. Menu/document OCR is unchanged.
- Simple controller + translation-bubble logo: editable source
  `design/gamelingo-logo.svg`, reproducible rendering script
  `tools/generate-branding.py`, opaque 1024px iOS AppIcon asset catalog, matching
  Android vector. Control Center uses the system `gamecontroller.fill` symbol.
- iOS app and extension build numbers are 12; Android versionCode is 14.
  Marketing versions stay 0.5.0 and package identifiers/signing groups are unchanged.

## Physical acceptance after successful CI

1. Sign the app and embedded control extension with compatible App Group
   entitlements. Retain the extension and test with saved console/model settings.
2. Add or re-add the GameLingo control; verify the controller icon and app logo.
3. Start with the app foreground, background, suspended, and terminated normally.
   Record force-quit behavior separately. Confirm the UI is not opened by a press.
4. Press off during loading, reconnecting, and streaming. Confirm native work
   stops, the state updates, and the control can start another session.
5. With the background experiment disabled, confirm expiration suspends work
   and does not claim permanent execution. Repeat with the existing experiment
   enabled and real interruptions; record observed duration, not assumptions.
6. Verify vehicle plates/HUD noise is reduced in gameplay, real numerical
   dialogue still translates, and menus/documents still show their useful numbers.
