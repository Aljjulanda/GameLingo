# GameLingo 0.5.0 (11) implementation checkpoint

The owner requested that work stop after checking and building to reduce consumption. This is a development checkpoint, not real-device acceptance of the entire upgrade specification. Source branch: `codex/gamelingo-0.5.0`; implementation commit: `d1fcd74`; Android CI setup correction: `d5cf04f`.

## Changes

- Native Chiaki disconnect reasons are mapped into bridge-owned causes. A separate console lifecycle tracks active, waiting, recovery, suspension, and explicit-activation states. Rest/shutdown/ambiguous remote termination cancels retries. Retry requires a fresh READY discovery response after interruption; a console that cannot be confirmed available is eventually stopped. Recovery has no wake command. Suspension preserves intent separately from explicit Stop.
- Added an iOS 18 WidgetKit Controls extension, `ControlWidgetToggle`, shared App Group connection-state snapshots, short state leases, and a `SetValueIntent` in both target memberships. Actions foreground the app, consume the saved configuration, and report actual connection rather than requested intent. iOS 16/17 retain in-app controls. The unsigned archive/signing workflow remains in place; signing must include the extension and App Group entitlement.
- Gameplay starts local learning automatically. Bounded ingress, OCR/dialogue/speaker/translation evidence, conservative privacy/content filters, repeated observations, and independent exact-pack references gate automatic memory approval. Repeated Argos output alone is never authority. This updates translation memory, not Argos parameters. Existing explicit corrections retain priority.
- Added a dedicated, low-priority full-screen spatial OCR worker, relative luma fingerprinting, text/layout anchors, automatic screen categories, and indexed SQLite translation/screen storage. Observed text is revalidated before recall; no screenshots are persisted. Exact text translations can be recalled across layouts; changed dynamic values have distinct keys. UI text does not enter the learning worker.
- Added protected indexed fuzzy candidate retrieval on the existing pack indexes, preserving negation, pronouns, numbers, directions and names. Short/ambiguous candidates are rejected. Added OCR/fuzzy/learning diagnostic origins and counters.
- Added `spatial_v1` capability negotiation to the existing authenticated TV menu protocol. The TV positions Arabic regions in an aspect-fit viewport, clips/shrinks text to each region, and suppresses collisions. Legacy manual menu rendering remains supported. Region leases expire without fresh updates.
- Removed visible source badges at both the iPhone wire producer and TV renderer. Source metadata remains available to internal diagnostics.
- Stop now retires the local translation engine/cache as well as Remote Play and the frame pipeline. Memory warnings trim transient caches. RSS export includes startup/model-load/model-release/session/idle checkpoints and a sampled peak. These are whole-process measurements, not allocator attribution.
- iOS version is 0.5.0 (11); TV version name is 0.5.0 and version code increases to 13, preserving package identity.

## Persistence and migration

Existing console credentials, settings, profiles, imported packs, names and explicit correction files retain their paths and formats. Optional learning evidence decodes old records. Privacy filtering removes excluded legacy observations before future persistence. Spatial storage is additive: `Application Support/SpatialUI/screens.sqlite`, schema `user_version=1`, transaction-based creation, WAL, 1 MiB page cache, no mmap, bounded records (1,000 layouts / 20,000 text translations). Unsupported newer schema versions fail closed. Pack databases remain immutable; fuzzy matching uses existing indexes and bounded candidate windows rather than importing a corpus into RAM.

## Limits at this checkpoint

No iPhone/PS5/HDMI TV hardware test, Instruments allocation/leak capture, sustained 60-minute session, or measured RSS/CPU/latency improvement was performed. The requested sub-500 MiB RSS remains an unverified target. There is no evidence yet explaining the reported 1.33 GiB increase by individual allocator/component.

The screen classifier is conservative and heuristic, not a trained universal game UI recognizer. Low-confidence and unsupported screens may remain untranslated. Dense text can be clipped/ellipsized or withheld to avoid overlap. Imported UI templates, semantic Arabic model validation, mission inference, generalized OCR correction training, and context-resolved ambiguous pack matching are not complete. The context-resolved diagnostic counter is reserved and does not imply that such matching occurred. Learning export separates evidence categories, but does not constitute a new fully normalized learning database or a comprehensive repair of an unavailable historical `export.json`.

Automatic spatial work currently coexists with the existing manually enabled menu mode by yielding to that legacy path. That configuration still needs reconciliation before claiming universal automatic UI discovery. Memory cleanup and asynchronous output fencing need device stress testing, particularly Stop/start/reconnect races. No absence of regressions is claimed from host tests alone.

Widget actions intentionally open the containing app; they do not grant unlimited background Remote Play/Vision execution. The existing optional background-audio mechanism remains, subject to iOS execution policy. A disabled background experiment's timeout is not evidence that the mechanism is broken. Control refresh is subject to system scheduling; a short persisted state lease prevents a freshly queried control from treating an old process state as active.
